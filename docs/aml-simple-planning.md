# AML 简化检索规划（可选）

`SEREIN_AML_SIMPLE_PLANNING=1` 启用；默认关闭，与写入 Router/Curator、SOURCE_EVIDENCE、独立时间注记实验无关。

读卷规划只要求现有 `arc_key` 与 `picks`，缺口文字可选。不再要求 sufficient、supports、逐字引文和缺口索引彼此一致。非负整数编号及其纯数字字符串可接受；bool、float、负数、未知菜单或编号不接受。单个无效选择不再让其他合法选择失效，最多五项。空选择正常结束，不强制开卷。

读后复核只输出已提供的 selection ID。程序保留实际读取的两端正文作为内部来源上下文，模型不生成交付正文或因果链。这个内部上下文不证明因果正确。现有 Reader 当前版本、域、卷来源可读性、用户隔离、组完整性和输出预算仍有效。来源正文作为 focus 时，预算较小时可能影响分配；没有取消总预算或保证所有材料都可交付。

缺口搜索仍须引用现有 anchor 和其中出现的实体；程序从该 anchor 选取包含实体的原文窗口，最多两个查询。原话回读仍按需，未改成无条件读取。关联实体两端出现检查仍保留，单纯出现相同实体不代表因果成立。

匿名状态细分菜单、编号、搜索锚点、复核格式等拒绝；只记录固定阶段和数量，不记录问题、原话或模型输出。`arc_review_not_selected` 表示未被接受的数量，不能单独解释模型的语义判断。旧路径的统一 invalid 状态保持原样。

本地验收先覆盖合法选择与错误混合、缺口缺省、跨用户隔离、域排除、跨 Event 读取和预算，再做有界真实 mini 合成验收。完成一组变更后才考虑一次官方 Smoke；Smoke 的少量题不能定位某个程序分支，也不能证明完整能力。此轮不实现完整时间线、状态治理或时期全量覆盖，后续按计划独立补齐。
