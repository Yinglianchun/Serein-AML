## 表 S2. 数据对象与处理职责

| 对象 | 本文中的含义 | 在流程中的作用 |
| --- | --- | --- |
| 原始消息 | 带稳定标识、时间、说话者和内容的记录 | 可按标识读回，是判断和写作的依据 |
| Track | 保存消息成员、简短主线描述和跨线关系的话题线 | 组织后续材料及历史候选，不直接决定 Event 边界 |
| 完整对话 | 用于判断材料是否可以开始处理的交互范围 | 服务调度与完整性判断，不自动构成归属单元 |
| 归属单元（unit） | 本轮模型必须整体处置的来源集合 | 由当轮输入合同界定；相邻问答不会自动扩大其边界 |
| Track 组件（component） | 按声明的跨线关系组合出的有界阅读范围 | Curator 在其中一起判断相关单元及旧 Event 候选 |
| Event | 经历正文、绑定来源及修订关系 | 保存新经历，或替换所选旧记录并保留前身与后继 |

## 表 S3. Curator 处置与前身条件

| 处置 | 含义与旧 Event 条件 |
| --- | --- |
| create | 形成新的 Event，不选择旧记录 |
| extend | 续接一条旧 Event，选择一个前身 |
| merge | 将经历组织为一个后继，选择至少两个前身 |
| skip | 本轮材料不形成 Event，也不进入其来源 |
| defer | 按合同暂缓：稳定内容仍被未稳定尾部承接或纠正，或相关前身受到替换保护 |
